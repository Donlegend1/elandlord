# Afrik Minerals — Laravel + Inertia + React

A modern, SEO-friendly rebuild of a gold/diamond trading company site, using
Laravel, Inertia.js, and React. Business contact details are placeholders —
search for `[YOUR` to find every spot that needs your real information.

This folder contains the **application-specific files only** (controllers,
models, routes, migrations, and the full `resources/js` React frontend). It's
meant to be dropped into a fresh Laravel install rather than run standalone,
since a real Laravel app also needs `vendor/`, `bootstrap/`, and framework
config files generated by the installer.

## 1. Create the base Laravel app

```bash
composer create-project laravel/laravel afrik-minerals
cd afrik-minerals
```

## 2. Install Inertia (server side) + Ziggy (for the `route()` helper in JS)

```bash
composer require inertiajs/inertia-laravel tightenco/ziggy
php artisan inertia:middleware
```

Register the middleware in `bootstrap/app.php` (Laravel 11) inside the
`->withMiddleware()` callback:

```php
$middleware->web(append: [
    \App\Http\Middleware\HandleInertiaRequests::class,
]);
```

## 3. Copy this project's files into place

Copy everything from this folder into your new Laravel app, overwriting
where prompted:

- `app/Http/Controllers/*`
- `app/Http/Middleware/HandleInertiaRequests.php`
- `app/Models/*`
- `database/migrations/*`
- `database/seeders/*`
- `routes/web.php`
- `resources/js/*`
- `resources/css/app.css`
- `resources/views/app.blade.php`
- `resources/views/sitemap.blade.php`
- `vite.config.js`, `tailwind.config.js`, `postcss.config.js`
- `public/robots.txt`

## 4. Install JS dependencies

```bash
npm install
npm install -D tailwindcss postcss autoprefixer
```

## 5. Configure environment

Copy the values from `.env.additions` into your `.env` file.

## 6. Database + images

```bash
php artisan migrate --seed
```

Add real photos to:
- `public/images/products/` — filenames matching the `image` column seeded
  in `ProductSeeder` (e.g. `gold-bars.jpg`)
- `public/images/gallery/` — `gallery-1.jpg` through `gallery-9.jpg`
- `public/images/logo.png` and `public/images/og-cover.jpg`

## 7. Run it

```bash
composer run dev
# or, in two terminals:
php artisan serve
npm run dev
```

## Filling in real business details

Search the project for `[YOUR` — every instance marks a placeholder:

- `resources/views/app.blade.php` — Organization structured data (email, phone)
- `resources/js/Components/Footer.jsx` — footer contact block
- `resources/js/Pages/Contact.jsx` — contact page details
- `public/robots.txt` — replace `your-domain-here.com` with your real domain

## SEO notes

- Every page sets its own `<title>`, meta description, and canonical URL via
  `resources/js/Components/Seo.jsx` and Inertia's `<Head>` — check each Page
  file if you add new routes.
- `/sitemap.xml` is generated dynamically from the routes and product catalog
  (`app/Http/Controllers/SitemapController.php`).
- Product pages emit `Product` JSON-LD structured data; the homepage emits
  `Organization` JSON-LD.
- Server-rendered content (via Inertia's initial page load) means crawlers
  see full HTML on first request, unlike a client-only SPA.
- For best crawlability in production, consider adding Inertia SSR
  (`@inertiajs/react` supports it via `php artisan inertia:start-ssr`) — this
  scaffold ships client-side rendered, which is sufficient for modern
  Google/Bing crawlers but SSR is a further improvement for other bots.
